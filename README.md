# Умная интеграция YCLIENTS и amoCRM на n8n (Защита от дублей)

Готовый шаблон (Workflow) для n8n, который решает главную боль стандартных виджетов интеграции — бесконечное создание дублей сделок при повторной записи клиента.

## 🔴 Проблема стандартных решений
Обычная интеграция YCLIENTS и amoCRM работает прямолинейно: клиент записался на услугу -> система тупо создает новую сделку. Если это постоянный клиент, с которым уже идет работа в другой воронке, менеджеры получают кашу из дублей. Воронка засоряется, аналитика по LTV ломается, РОП ругается.

## 🟢 Как работает эта архитектура
Этот воркфлоу перехватывает вебхук от YCLIENTS и работает умнее:
1. Ловит номер телефона из новой записи.
2. Ищет активные сделки с этим контактом в amoCRM.
3. **Если сделка есть:** НЕ создает дубль. Система аккуратно дописывает детали новой записи (дата, время, услуга, мастер) в примечание к существующей сделке.
4. **Если сделки нет:** Создает новую карточку по всем правилам.
5. Отправляет алерт руководителю или администратору в Telegram.

## 🛠 Что под капотом (Техническая реализация)
Вся работа с amoCRM построена на чистых `HTTP Request` (REST API v4). Никаких тяжелых встроенных UI-нод. Это дает максимальную скорость отклика, 100% контроль над передаваемыми JSON-данными и защиту от отвалов при обновлениях n8n.

**Логика работы узлов:**
1. `Webhook` — Мгновенно ловит POST-запрос от YCLIENTS.
2. `Set (Нормализация)` — Очищает номер телефона от мусора (RegEx `\D`), форматирует дату, вытаскивает сумму и название услуги.
3. `HTTP Request (Поиск контакта)` — GET-запрос к API amoCRM. Ищет клиента по нормализованному номеру.
4. `IF + HTTP Request (Создание)` — Если контакта нет, система создает его. Если есть — забирает его ID.
5. `HTTP Request (Поиск сделок)` — Проверяет массив `_embedded.leads` у найденного контакта.
6. `IF (Статус сделки)` — Фильтрует сделки. Если статус равен 142 или 143 (Успешно/Закрыто) — они игнорируются.
7. `HTTP Request (Примечания)` — Ключевой узел. Если есть активная сделка, система отправляет POST-запрос в `/api/v4/leads/{id}/notes` и аккуратно дописывает данные о новой записи из YCLIENTS, не создавая дубль карточки.
8. `Telegram` — Отправляет РОПу форматированный HTML-алерт с прямой ссылкой на сделку.

## 🚀 Как установить
1. Скачайте файл `yclients-amocrm-logic.json` из этого репозитория.
2. В вашем инстансе n8n в правом верхнем углу нажмите `Import from File`.
3. Подключите свои Credentials для amoCRM (OAuth2/Long-lived token) и Telegram API.
4. Замените URL вебхука в YCLIENTS на сгенерированный адрес из первой ноды.
5. Активируйте Workflow.
